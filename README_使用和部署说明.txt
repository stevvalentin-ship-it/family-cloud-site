二、已经做好的功能
- 四位家庭成员固定登录
- 家庭状态墙
- “需要电话”醒目提醒
- 一键报平安
- 一键标记需要电话
- 家庭留言板
- 家庭待办清单
- 家庭时光照片/文件上传入口
- 本机预览模式
- Supabase 云端同步模式
- 适配电脑和手机

三、本机预览
双击 start_preview.bat。
浏览器打开：
http://localhost:8031/

四、云端共享需要做的一次性步骤
如果你希望父亲、母亲、我、奶奶在不同电脑或手机打开同一个网址后看到共同内容，需要先到 Supabase 运行一次 SQL。

1. 打开 Supabase 项目。
2. 进入 SQL Editor。
3. 打开本文件夹里的：
   supabase/family-site-setup.sql
4. 复制里面全部内容。
5. 粘贴到 Supabase SQL Editor。
6. 点击 Run。

运行成功后，网站右上角会从“本机预览”变成“云端已连接”。

五、发布成独立网址
推荐新建一个 GitHub 仓库，例如：
family-cloud-site

然后把本文件夹上传到这个新仓库，再在 GitHub Pages 中选择：
Source: Deploy from a branch
Branch: main
Folder: / (root)

这会得到一个独立网址，不会影响数学建模网站。

六、重要提醒
这个网站使用固定姓名和固定密码，适合家庭内部轻量使用。
不要把真正的身份证、银行卡、医院病历等敏感内容放进去。
